# SashEnergy

Мобильный дневник дегустаций энергетических напитков. В приложении можно искать напитки, ставить им оценку, собирать личный топ-3 и отслеживать общий прогресс по каталогу.

## Возможности

- каталог энергетиков России и Азии;
- поиск по названию;
- оценка от 1 до 5 звёзд;
- отдельный список энергетиков, которые пользователь не планирует пробовать;
- список «Я пробовала» с сортировкой по рейтингу;
- личный топ-3;
- уровни и общий прогресс по каталогу;
- полноэкранный просмотр фотографии по долгому нажатию;
- локальное сохранение данных в браузере.

## Локальный запуск

Проект не требует сборки или установки зависимостей. Запустите любой статический сервер из корня репозитория, например:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`.

Файл `.nojekyll` уже добавлен, поэтому GitHub Pages будет отдавать проект как обычный статический сайт.

## Данные пользователя

Оценки, прогресс, пользовательские фотографии и топ-3 сохраняются только в локальном хранилище текущего браузера. Они не отправляются на сервер и не синхронизируются между устройствами.
